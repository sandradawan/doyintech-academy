# Doyintech Academy

Learn to code with short videos, written lessons, interactive exercises, quizzes, and a named certificate.

A school from [DoyinTech](https://doyintech.vercel.app) — production engineering for African businesses, now teaching the same standard.

**Live product is being built in phases.** This repository tracks the public source of truth.

## What students get

- **Courses** with a real syllabus (video, reading, in-browser exercises)
- **Quizzes** with a 70% pass mark
- **Certificates** with the student’s name, course, date, and a unique ID

## Build phases

1. **Foundation (this phase)** — brand, landing, course catalog, GitHub repo
2. **Accounts** — sign-in, dashboard, enrollment, progress
3. **Classroom** — lesson player (video + text + live exercises)
4. **Proof** — quizzes and named certificates
5. **Ship** — polish and full source in this repo

## Stack

React 19, TanStack Start, Tailwind CSS. Preview and production share the same app.
