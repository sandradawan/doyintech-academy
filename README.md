# Doyintech Academy

Learn to code with short videos, written lessons, interactive exercises, quizzes, and a named certificate.

A school from [DoyinTech](https://doyintech.vercel.app).

## Features

- Course catalog (6 paths)
- Student accounts (on-device)
- Dashboard with progress
- Certificates after 70% quiz
- Admin CMS at `/admin` (PIN: `doyin2026`)
- Homepage waitlist for first cohort

## Stack

Next.js App Router, React 19, TypeScript, Tailwind CSS v4.

## Getting started

```bash
npm install
npm run dev
```
